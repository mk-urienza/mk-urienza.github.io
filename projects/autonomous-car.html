Autonomous Camera-Based Vehicle

A camera-guided autonomous vehicle combining custom PCB hardware, OpenMV computer vision, lane geometry, closed-loop speed control, and PWM steering.

Primary Technical Contributor Winter–Spring 2025 Python OpenMV Altium Designer

01

Overview

The project required an autonomous vehicle to remain inside a marked track while completing a timed run. The system combined camera-based lane detection, steering control, speed measurement, PID correction, motor control, and custom vehicle electronics.

I designed the vehicle PCB in Altium and implemented the majority of the camera-guided control software, including the lane geometry and control logic used by the vehicle during autonomous operation.

Result

The project placed Top 3 and was demonstrated during the UC Davis engineering open house.

02

System Architecture

The software pipeline converted each camera frame into steering information while a separate control loop measured vehicle speed and updated the motor PWM.

03

Camera Processing

The OpenMV camera operated in grayscale at QQVGA resolution. Two regions of interest were used to independently estimate the left and right lane boundaries.

main.py Python 
roi_left = (0, 30, 30, 30)
roi_right = (50, 30, 30, 30)

line_left = img.get_regression(
    [(255, 255) if BINARY_VISIBLE else THRESHOLD],
    roi=roi_left,
    robust=True
)

line_right = img.get_regression(
    [(255, 255) if BINARY_VISIBLE else THRESHOLD],
    roi=roi_right,
    robust=True
)
Why this matters

Splitting the lower image into separate left and right regions prevents the algorithm from treating the entire track as a single feature. Each detected lane boundary can instead contribute independently to the estimated track center.

04

Lane Geometry

Rather than steering directly from one detected line, the software projects both lane boundaries onto common image rows and calculates the midpoint between them.

main.py Lane center calculation 
def x_at_y(l, y):
    x1, y1, x2, y2 = l.line()

    if x2 == x1:
        return x1

    m = (y2 - y1) / (x2 - x1)

    if m == 0:
        return (x1 + x2) // 2

    return int((y - y1) / m + x1)


def midpoint_line(l_left, l_right, y_lo, y_hi):

    xl_lo = x_at_y(l_left, y_lo)
    xl_hi = x_at_y(l_left, y_hi)

    xr_lo = x_at_y(l_right, y_lo)
    xr_hi = x_at_y(l_right, y_hi)

    xm_lo = (xl_lo + xr_lo) // 2
    xm_hi = (xl_hi + xr_hi) // 2

    return (xm_lo, y_lo, xm_hi, y_hi)
Engineering approach

The midpoint line estimates the path the vehicle should follow between the detected lane boundaries. Its horizontal position provides lateral error, while its angle provides information about the direction of the track.

05

Steering Control

With an 80-pixel-wide image, the camera center is located near x = 40. The control software calculates the difference between the detected lane midpoint and the image center.

main.py Steering correction 
midpoint = (xl_lo + xr_lo) / 2
err_px = midpoint - 40

if abs(err_px) > 2:
    pulse = int(err_px * -3000)

elif abs(err_px) < 2:
    pulse = int(deflectionAngleDeg * 2500)

target_ns = sc + pulse

if target_ns < sr:
    target_ns = sr

elif target_ns > sl:
    target_ns = sl

servo.duty_ns(target_ns)

Larger lateral errors prioritize correction toward the center of the lane. Once the vehicle is close to the center, track angle is used to anticipate the direction of travel.

06

Single-Lane Recovery

Sharp turns or camera positioning could temporarily remove one lane boundary from the image. Instead of immediately abandoning steering control, the software falls back to the angle of the remaining detected line.

main.py Recovery behavior 
elif line_left or line_right:

    line = img.get_regression(
        [(255, 255) if BINARY_VISIBLE else THRESHOLD],
        robust=True
    )

    x1, y1 = line.x1(), line.y1()
    x2, y2 = line.x2(), line.y2()

    if y1 != y2:
        deflectionAngle = math.atan(
            (x1 - x2) / float(y1 - y2)
        )
    else:
        deflectionAngle = 0

    deflectionAngleDeg = math.degrees(
        deflectionAngle
    )

    pulse = int(deflectionAngleDeg * 9500)

    target_ns = sc + pulse

    if target_ns < sr:
        target_ns = sr

    elif target_ns > sl:
        target_ns = sl

    servo.duty_ns(target_ns)
Failure recovery

This gives the vehicle a temporary steering strategy when only one lane boundary remains visible instead of immediately losing all control.

07

PID Speed Control

Wheel rotation pulses were counted through an interrupt and converted into angular velocity. The measured speed was then compared with a target speed.

main.py Closed-loop speed control 
Angular_Velocity = (
    count * angle_per_pulse
) / (dt_ms / 1000.0)

error = SET_SPEED_DPS - Angular_Velocity

pid_integral += error * dt_s

derivative = (
    (error - pid_prev_error) / dt_s
    if dt_s > 0
    else 0
)

control = (
    (KP * error)
    + (KI * pid_integral)
    + (KD * derivative)
)

motor_pwm = int(
    max(
        MOTOR_MIN,
        min(MOTOR_MAX, control)
    )
)

motor.duty_u16(motor_pwm)

08

Lost-Track Behavior

A frame counter tracks how long the system operates without detecting either lane. After enough failed frames, the motor command transitions to the configured brake value.

09

Hardware Integration

I designed the vehicle PCB in Altium to integrate the OpenMV controller, motor-drive electronics, voltage regulation, MOSFET switching, filtering, servo connections, and high-current routing.

The software then interacted directly with the integrated system through PWM motor and servo outputs and an interrupt-driven wheel-speed signal.
