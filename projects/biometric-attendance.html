Biometric Attendance System

An embedded attendance system using a TI CC3200, fingerprint authentication, IR remote control, an OLED interface, UART and SPI peripherals, and AWS IoT-backed attendance records.

Primary Implementation Winter 2025 C CC3200 AWS IoT

01

Overview

The system was designed to allow students to enroll a fingerprint, associate that fingerprint with a student ID and name, and later authenticate themselves to log attendance.

The project combined embedded C, UART fingerprint communication, SPI display control, GPIO interrupts, an IR remote user interface, menu-state logic, and cloud communication through AWS IoT.

02

Fingerprint Interface

The fingerprint library was adapted for the CC3200 application by connecting the library's generic serial callbacks to the microcontroller's UART functions.

main.c UART abstraction 
int MyUARTRead(void) {

    int c =
        MAP_UARTCharGet(UARTA1_BASE);

    return c;
}


int MyUARTAvail(void) {

    return MAP_UARTCharsAvail(
        UARTA1_BASE
    );

}


void MyUARTWrite(uint8_t b) {

    MAP_UARTCharPut(
        UARTA1_BASE,
        b
    );

}
main.c Fingerprint initialization 
Adafruit_Fingerprint_Init(
    &finger,
    0x00000000
);

finger.serial_read =
    MyUARTRead;

finger.serial_available =
    MyUARTAvail;

finger.serial_write =
    MyUARTWrite;

finger.delay_ms =
    MAP_UtilsDelay;

Adafruit_Fingerprint_Begin(
    &finger,
    57600
);
Porting strategy

Instead of depending on the original Arduino serial implementation, the fingerprint interface uses function pointers connected to the CC3200 UART hardware.

05

IR Remote Decoder

The remote-control receiver uses a GPIO interrupt to measure pulse timing. The pulse length determines whether each received bit is interpreted as a zero or a one.

main.c Interrupt-driven decoding 
void IR_GPIO_ISR(void) {

    unsigned long ulStatus =
        MAP_GPIOIntStatus(
            GPIOA2_BASE,
            true
        );

    MAP_GPIOIntClear(
        GPIOA2_BASE,
        ulStatus
    );

    current_time =
        SysTickValueGet();

    if (last_edge_valid) {

        pulse = time_elapse(
            last_time,
            current_time
        );

    }

    last_time =
        current_time;

    last_edge_valid = 1;

    IR_outflag = 1;
}
main.c Bit interpretation 
if (
    pulse >= T_1000US &&
    pulse <= T_1300US
) {

    received_data &=
        ~(1UL << bit_count);

    bit_count++;

}

else if (
    pulse >= T_2000US &&
    pulse <= T_2500US
) {

    received_data |=
        (1UL << bit_count);

    bit_count++;

}

07

Menu State System

Application behavior is organized into menu states representing student actions, enrollment, logging, administration, and the main menu.

main.c Application modes 
#define MAIN_MODE     1
#define STUDENT_MODE  2
#define ADMIN_MODE    3
#define LOG_MODE      4
#define ENROLL_MODE   5
main.c Main control loop 
while (1) {

    if (MENU_MODE == MAIN_MODE)
        MainMenu();

    if (MENU_MODE == STUDENT_MODE)
        StudentMenu();

    if (MENU_MODE == LOG_MODE)
        LogMenu();

    if (MENU_MODE == ENROLL_MODE)
        EnrollMenu();

    if (MENU_MODE == ADMIN_MODE)
        AdminMenu();

}

A student first enters a school ID. The system searches the local student records, requests fingerprint authentication, marks the student as logged in, and then sends the updated record to the cloud service.

Embedded-to-cloud integration

The CC3200 does not only authenticate the fingerprint locally. The application also creates a structured attendance record and communicates it to the remote IoT service.

10

Library Integration

The project includes supporting Adafruit and Texas Instruments library code. Rather than presenting those libraries as original work, the engineering contribution was the adaptation and integration of those interfaces into the CC3200 application.

The fingerprint driver uses CC3200 UART callbacks, while the OLED graphics and device initialization code are integrated into the complete menu and attendance workflow.
